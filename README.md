# MI Muhammadiyah Waru — Website Redesign

Redesign modern website resmi **MI Muhammadiyah Waru** (Baki, Sukoharjo, Jawa Tengah)
dengan identitas visual hijau zamrud & emas, konten asli dari mimwaru.sch.id.

## Fitur
- Hero carousel foto asli sekolah
- Jam & tanggal live Bahasa Indonesia
- News ticker berjalan
- Sambutan Kepala Madrasah (foto & teks asli)
- Visi & Misi, Profil Singkat (NPSN 30104429)
- Program Unggulan, Berita, Galeri foto asli
- Banner PPDB & footer kontak lengkap
- Fully responsive (mobile friendly)

## Teknologi
- HTML5 + CSS3 + Vanilla JavaScript (single page, tanpa framework)
- Semua aset (foto & logo) tersimpan lokal di folder `images/`

## Cara Menjalankan Lokal
Buka file `index.html` langsung di browser, atau jalankan server lokal:
```bash
python3 -m http.server 8000
# lalu buka http://localhost:8000
```

## Deploy
Website statis ini siap deploy ke GitHub Pages, Netlify, atau Vercel.
